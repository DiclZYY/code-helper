# 仓库目录结构与边界

让前端、后端、发布脚本边界清晰，降低耦合与误改概率。

## 顶层目录（约定）

- `backend/`：Vue2 管理后台工程（构建、静态资源、前端路由等）
- `api/`：Laravel API 工程（业务接口、数据库、队列/任务、权限等）
- `docs/`：文档根目录；`docs/framework/` 为工程规范；`docs/requirements/` 为需求与功能设计文档
- `transfer/`：如存在，用于发布 / 迁移过程中的中间产物或传输文件（以实际代码为准）

## 严格边界（硬约束）

- **禁止**在 `backend/` 里直接引用 / 修改 `api/` 的业务代码逻辑（仅通过 HTTP API 联调）。
- **禁止**在 `api/` 里依赖前端构建产物的源码路径做业务判断。
- **全局函数**：`api/functions/helpers.php` 仅允许放「通用、稳定、无副作用」的工具函数，禁止塞业务逻辑。

## 约定性命名

- 前端：组件、页面、store、router 的组织方式以 `frontend-vue2.md` 为准。
- 后端：路由、控制器、服务层、模型、资源（Resource）组织方式以 `backend-laravel.md` 为准。
