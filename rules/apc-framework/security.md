# 安全与敏感信息

本规则定义 apc 框架的「最低安全基线」。任何违反本基线的做法都应视为缺陷并立即修正。

## 绝对禁止入库

- `api/.env`、`backend/.env*`（如包含真实密钥 / 账号）
- 私钥（SSH、JWT、RSA 等）、访问令牌、第三方平台密钥
- 生产数据库连接串、云账号密钥、对象存储密钥

如必须提交示例配置，使用：

- `.env.example`（示例值必须脱敏、不可用）
- 或在 `rules/apc-framework/` 记录「需要哪些变量 + 含义 + 示例格式」

## 日志脱敏

- 禁止记录：密码、验证码、token、完整身份证号、完整银行卡号等。
- 必要时只记录尾号 / 哈希，或记录业务主键以便回溯。

## 依赖与供应链

- 新增依赖必须说明用途与替代方案，并更新 `tech-stack.md`。
- 私有依赖（如 `lis/admin-service`）的更新需要明确版本来源、变更点与回滚策略。
