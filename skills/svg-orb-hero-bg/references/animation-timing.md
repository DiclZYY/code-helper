# 动画时长互质与轨迹设计

## 为什么时长要错开

若所有光球的 X/Y/旋转动画使用相同或整除关系的时长，轨迹将呈严格周期，视觉上很快产生「重复感」。通过 **互质或近互质** 的时长组合，可使整体运动在数十秒内不重复，形成「有机流动」。

## 基础时长表

| 层级 | 默认基数 | 说明 |
|------|----------|------|
| X 轴 | 10s ~ 13s | 水平漂移 |
| Y 轴 | 6s ~ 12s | 垂直漂移 |
| 旋转 | 7s ~ 12s | 自转 |

## 互质组合示例

以下数字的最大公约数尽可能小：

```text
orb-1:  X=10s,  Y=10.5s, R=7s   → GCD(10, 10.5)=0.5
orb-2:  X=11.5s, Y=12s,   R=12s → GCD(11.5, 12)=0.5
orb-3:  X=12.5s, Y=6s,    R=9s  → GCD(12.5, 6)=0.5
```

整体循环周期 ≈ LCM(10, 10.5, 7, 11.5, 12, 12.5, 6, 9) ≈ 数千秒，肉眼不可感知重复。

## 速度倍率变量

通过 CSS 变量统一缩放：

```css
:root {
  --orb-speed: 1;        /* 正常 */
  --orb-speed: 1.5;      /* 慢速，更舒缓 */
  --orb-speed: 0.6;      /* 快速，更活跃 */
}

.orb-1-x { animation-duration: calc(10s / var(--orb-speed)); }
```

所有时长同步缩放，互质关系保持不变。

## 平移幅度设计

| 场景 | translateX/Y 幅度 | 效果 |
|------|-------------------|------|
| 保守 | 0% ~ 15% | 轻微呼吸感，适合金融/医疗类品牌 |
| 标准 | 0% ~ 25% | 明显流动，通用方案 |
| 夸张 | 0% ~ 40% | 强烈动感，适合游戏/创意类 |

## prefers-reduced-motion

```css
@media (prefers-reduced-motion: reduce) {
  .orb-x, .orb-y, .orb-r {
    animation-play-state: paused;
  }
}
```

必须保留，符合无障碍规范。
